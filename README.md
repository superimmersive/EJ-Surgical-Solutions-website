# EJ Surgical Solutions

Modern e-commerce website for [EJ Surgical Solutions](https://ejsurgicalsolutions.co.za/) — a medical and surgical equipment supplier based in George, South Africa.

## Features

- **Homepage** with company branding, why choose us, founder, values, and testimonials
- **About & Contact** pages with real business details
- **Product catalog** matching EJSS categories (gloves, syringes, sutures, wound dressings, etc.)
- **Shopping cart & checkout** with ZAR pricing and nationwide delivery
- **Responsive design** for mobile, tablet, and desktop

## Quick Start

```bash
npm install
npm run dev
```

Open **http://localhost:5173**
